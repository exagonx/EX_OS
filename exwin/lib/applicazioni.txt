# L'elenco delle applicazioni grafiche di EX-OS.
#
# ! AGGIUNGERE UN'APPLICAZIONE E' UNA RIGA, NON UNA RICOMPILAZIONE. Il program
# manager legge questo file all'avvio: un elenco compilato dentro il binario
# vorrebbe dire rifare il program manager per ogni applicazione nuova, e chi
# installa un programma non ha i sorgenti.
#
# ! E DAL 19 AGOSTO 2026 NON SERVE NEMMENO UN EDITORE DI TESTO: il menu di
# avvio aveva la voce «Applicazioni...», che aggiunge, toglie e riscrive questo
# file; dal 7 novembre 2026 e' il pulsante «Applicazioni del menu...» nella
# scheda Sistema di Impostazioni. Resta leggibile e modificabile a mano
# apposta — un file di configurazione che solo un programma sa scrivere e' un file che non si puo'
# riparare quando quel programma non parte.
#
# Una riga per applicazione:   nome mostrato | percorso dell'eseguibile
# Le righe che cominciano con # e quelle vuote si saltano.
#
# ! LE DIRETTIVE COMINCIANO CON @ E NON HANNO LA BARRA VERTICALE, che e' cio'
# che le rende impossibili da confondere con una voce: un'applicazione che si
# chiamasse «avvio» resta una voce, perche' ha la barra.
#
#   @avvio <percorso>   l'applicazione che parte DA SOLA quando la scrivania
#                       e' pronta. Una sola, e puo' anche non essere fra le
#                       voci qui sotto.
#
# ! L'AVVIO AUTOMATICO E' UNA DIRETTIVA A PARTE, NON UN SEGNO SULLA VOCE, e la
# differenza si vede appena serve: si puo' volere un programma che parte da
# solo e NON compare nel menu — un pannello, un orologio — oppure una voce di
# menu che non parte da sola. Legarli vorrebbe dire non poter fare ne' l'uno
# ne' l'altro.

# ! UNA VOCE PUO' AVERE UN TERZO CAMPO: l'ICONA, e si scrive come gli altri,
# dopo un'altra barra verticale. E' facoltativa — le righe senza restano righe
# buone — e il percorso e' assoluto, cioe' quello che avra' dentro EX-OS.
#
#   Nome | /percorso/eseguibile | /percorso/icona.ico
#
# ! E UNA BARRA NEL NOME FA UNA CATEGORIA: «Strumenti/Editor» vuol dire la voce
# «Editor» dentro «Strumenti», e nel menu «Strumenti...» apre un elenco DI
# FIANCO invece di avviare qualcosa. Le categorie compaiono in cima, nell'ordine
# in cui si incontrano qui dentro, e non si dichiarano da nessun'altra parte:
# esistono finche' c'e' una voce che le nomina.
#
# ! E UN QUARTO: QUANTA MEMORIA VUOLE, «ram=2048» (megabyte). Chi avvia la
# voce su una macchina che ne ha meno viene avvisato prima, e decide lui.
# Il terzo campo allora ci dev'essere, anche vuoto:
#
#   Nome | /percorso/eseguibile | /percorso/icona.ico | ram=2048
#
# Le icone di questo sistema sono a 64 e 128 pixel; il menu le rimpicciolisce
# da se' a 16 (vedi ex_icona_disegna in lib/exwin/exwin.h), quindi non serve
# una copia per ogni misura.
