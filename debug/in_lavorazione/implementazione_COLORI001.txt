2. IL MODELLO
-------------------------------------------------------------------------------
  colori.cfg / *.colori  --excol_leggi-->  ExColori (19 colori base +
                                           rifiniture + ritocchi)
                                              |
                                        excol_applica(schema, tema_base)
                                              v
                                           ExTema vivo (tavolozza intera
                                           di ~50 colori + forma)
                                              |
                       exwin.c (g_tema) <-----+-----> wserver.c (g_tema)

  - I 19 colori base (EXC_*): scrivania sopra/sotto, finestre, testo,
    caselle, testo nelle caselle, selezione, testo selezionato, barra
    attiva sinistra/destra, titolo attivo, barra inattiva sinistra/destra,
    titolo inattivo, luce e ombra del rilievo, suggerimenti e loro testo,
    pulsante di chiusura.
  - excol_applica ricava gli altri ~30 con regole fisse (excolori.c: per
    esempio puls_a = finestra schiarita di 28/255, luce2 = luce mescolata
    alla finestra al 59%, accento_chiaro = campo mescolato alla selezione
    al 27%). Le regole riconoscono le finestre scure (luminanza < 0.18) e
    scuriscono/schiariscono nel verso giusto (vedi schema_02_notte.png).
  - Lo schema "Classico" ridà la tavolozza di tema_01 con scarto massimo 12
    su un canale (verificato con un programma di prova sull'host; quattro
    valori di tema_01 sono stati portati a quelli ricavati).
  - I ritocchi ("!campo = #RRGGBB", fino a 16) forzano un campo qualunque
    della tavolozza per chi vuole controllare tutto: non hanno interfaccia
    nel pannello (resta semplice), si scrivono a mano nel file.

PASSO 2 - excolori nel toolkit

  lib/exwin/excolori.h, excolori.c (da debug/grafica/colori). Nel Makefile
  accanto a extema.o, in exwin.so e in wserver.drv.

  In exwin.c il tema non e' piu' un puntatore a una costante ma una copia
  viva:

    #include "excolori.h"

    static ExTema        g_tema_vivo;
    static const ExTema *g_tema = &extema_classico;
    static ExColori      g_schema;

    /* $HOME/.exwin/config/colori.cfg sopra lo schema del tema */
    static void tema_carica(void)
    {
        char p[200], buf[2048];
        const char *h = getenv("HOME");
        const ExTema *base = &extema_classico;   /* dopo: tema.cfg (TEMA001) */
        int fd, n;

        excol_da_tema(&g_schema, base);
        if (!h || !h[0] || !strcmp(h, "/")) h = getuid() == 0 ? "/root" : "";
        snprintf(p, sizeof(p), "%s/.exwin/config/colori.cfg", h);
        fd = open(p, O_RDONLY, 0);
        if (fd >= 0) {
            n = (int)read(fd, buf, sizeof(buf) - 1);
            close(fd);
            if (n > 0) {
                int ignote;
                buf[n] = 0;
                ignote = excol_leggi(&g_schema, buf, n);
                if (ignote) log_exwin("colori.cfg: %d righe non capite", ignote);
            }
        }
        if (g_schema.tema[0] && extema_per_nome(g_schema.tema))
            base = extema_per_nome(g_schema.tema);
        excol_applica(&g_schema, base, &g_tema_vivo);
        g_tema = &g_tema_vivo;
    }

  tema_carica() si chiama in ex_init(), prima della prima finestra, e
  quando arriva WIN_EV_TEMA (passo 3).

  wserver: la stessa funzione, con la HOME dell'utente a cui il server
  appartiene (voce 111: il server e' "<uid>:wserver"; la casa si ricava
  dall'uid con nome_utente() + /home/<nome>, o /root per 0). Il server
  disegna telai, barre e scrivania con g_tema.

PASSO 3 - Le tre funzioni nuove del toolkit e il cambio a caldo

    /* exwin.h */
    #include "extema.h"     /* gli header pubblici: va installato anche lui */
    int  ex_tela_di(ExWindow f, ExTela *t);       /* tela_di di TEMA001 */
    const ExTema *ex_tema_forma(const char *nome);/* extema_per_nome, o il
                                                     classico se non c'e' */
    void ex_tema_ricarica(void);                  /* chiede al server di far
                                                     rileggere i colori a tutti */
    const ExTema *ex_tema(void);                  /* il tema vivo (per chi
                                                     disegna da se': exide) */

    /* exwin.c */
    int ex_tela_di(ExWindow f, ExTela *t) { return tela_di(f, t); }
    const ExTema *ex_tema_forma(const char *n)
    {
        const ExTema *m = n && n[0] ? extema_per_nome(n) : 0;
        return m ? m : &extema_classico;
    }
    const ExTema *ex_tema(void) { return g_tema; }
    void ex_tema_ricarica(void)
    {
        if (g_pid_server) ipc_send(g_pid_server, WIN_MSG_TEMA, 0, 0);
    }

    /* win_proto.h */
    #define WIN_MSG_TEMA  0x5741    /* client -> server, senza dati */
    #define WIN_EV_TEMA   0x0041    /* server -> ogni client (evento) */

  Server, su WIN_MSG_TEMA: SOLO se il mittente (timbrato dal kernel,
  SYS_IPC_RECV_CHI, kernel 0.356) ha l'uid del server o e' root - un altro
  utente non deve poter far ridisegnare la sessione altrui. Poi:
  tema_carica(), ridisegna la scrivania (cache dello sfondo, TEMA001 4.4),
  sporca tutto lo schermo, e manda WIN_EV_TEMA a ogni client con almeno una
  finestra.

  Client, su WIN_EV_TEMA (nel giro dei messaggi del toolkit, non passato
  all'applicazione come evento suo): tema_carica(), poi per ogni finestra
  di primo livello disegna tutto e ex_update. Un'applicazione che disegna
  da se' (pm, exide, filemgr) riceve dopo un EXM_PAINT normale e rilegge i
  colori con ex_tema(): non serve altro.

  libc: aggiungere a lib/include/libc.h il prototipo
        int fsync(int fd);
  (la funzione c'e' in lib/libc.c, il prototipo manca; pm_colori.c lo
  dichiara da se' finche' non c'e').

PASSO 5 - Accessibilita' e robustezza

  - Lo schema "Alto contrasto" (09) e' la base per chi vede poco: in
    Impostazioni mettere anche una scorciatoia, Alt+Maiusc+Stamp come su
    altri sistemi, che lo applica e lo toglie (gestita da pm, che e' sempre
    in esecuzione). Facoltativo.
  - Un colori.cfg rovinato non puo' fare danni: excol_leggi ignora le righe
    sbagliate e i colori malformati, il resto resta quello del tema.
    Scrivendo, pm passa da <file>.nuovo + rename (scrivi_file): un
    salvataggio interrotto non lascia un file a meta'.
  - Il server ignora WIN_MSG_TEMA da altri utenti (passo 3).
